AutoStock Detroit - Power BI project (English)

1. Unzip into a NEW folder: C:\Users\cbuqu\Downloads\AutoStock_PowerBI_EN\ (do not extract over the old French folder).
   The Excel workbook must stay next to AutoStock.pbip. If you move the folder, change the FilePath parameter:
   Home > Transform data > Edit parameters.

3. Refresh, then File > Save as to get a regular .pbix file.
